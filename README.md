# Nodeway

Ten interactive poker navigation concepts built to help choose a direction for Owen's app.

Open `index.html` in a browser. No install, build step or server is needed.

1. Decision tree
2. Guided journey
3. Study library
4. Table explorer
5. Range explorer
6. Hand replay
7. Compare lines
8. Visual atlas
9. Quick find
10. Node canvas

All data and charts are illustrative, not solver calculations or poker recommendations. Shortlists are saved only in the browser's local storage.

The hosted preview is managed separately through ChatGPT Sites; pushing here does not automatically redeploy that preview.
